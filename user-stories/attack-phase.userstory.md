As a player who has chosen to attack with their zombie hero, I want to be guided through the attack phases.

The attack phases are:
1) Roll the dice. The UI should ask how many dice to roll, pre-filling the field with the value given by Hunger + Base Attack Value (Base Attack Value is a new property to be added to the HeroCard).
2) Count how many "Hunger" results came up from the dice roll. The UI should ask for the count. Once confirmed, Hunger should be incremented accordingly (respecting the maximum of 4).
3) Ask how many valid attacks were rolled.
4) For each valid attack rolled, the zombie hero's level is incremented.
